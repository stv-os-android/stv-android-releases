# STV OS para la TrimUI Smart Pro S

![La pantalla de inicio de STV OS en la TrimUI Smart Pro S](images/es/home.png)

**Última versión:** 0.0.1-beta (2026-10-10)

**Qué es STV OS**, qué cambia en la consola y los resultados medidos en PSP: [Presentación](overview.es.md).

## ¿Dónde se instala?

- **Memoria interna:** reemplaza el firmware de fábrica.
- **Tarjeta microSD:** el firmware de fábrica queda intacto.

[Cuál elegir](releases.es.md#qué-instalación-elegir)

## ¿Dónde descargo la última versión?

Hay un archivo para cada instalación en [Versiones disponibles](releases.es.md#versiones-disponibles).

## ¿Cómo se instala?

- [En la memoria interna](releases.es.md#instalar-en-la-memoria-interna): un archivo en una tarjeta FAT32 y
  una combinación de botones.
- [En una tarjeta microSD](releases.es.md#instalar-en-una-tarjeta-microsd): Raspberry Pi Imager en una
  computadora.

## ¿Qué hago después de instalar?

Siga [Después de instalar](releases.es.md#después-de-instalar): idioma, zona horaria, Wi-Fi y dónde copiar
los juegos.
