# STV OS para la TrimUI Smart Pro S

**[Presentación](overview.es.md)** · **[Versiones](releases.es.md)** · **[Manual](manual.es.md)**

## Inicio rápido

1. **Elija** dónde instalarlo: [memoria interna o tarjeta microSD](releases.es.md#qué-instalación-elegir).
2. **Descargue** el archivo de esa instalación en [Versiones disponibles](releases.es.md#versiones-disponibles).
3. **Instálelo** siguiendo los pasos: [memoria interna](releases.es.md#instalar-en-la-memoria-interna) o
   [tarjeta microSD](releases.es.md#instalar-en-una-tarjeta-microsd).
4. **Configure** el idioma, la zona horaria y el Wi-Fi en Ajustes STV, y copie sus juegos a
   `Roms/<sistema>/` ([manual](manual.es.md#los-juegos-y-la-carpeta-roms)).
