| | |
|---|---|
| Última versión | **0.0.1-beta** (2026-10-10) · [descargar e instalar](releases.es.md) |
| Sistema | Android 13, kernel propio (Linux 5.15) |
| Consola | TrimUI Smart Pro S (Allwinner A523, 1 GB de RAM, GPU Mali-G57, pantalla de 1280×720) |
| Se instala en | la **memoria interna** (reemplaza el firmware de fábrica) o una **tarjeta microSD** (el firmware de fábrica queda intacto) |
| Objetivo principal | PSP a velocidad completa, a más resolución que la original, en los juegos más pesados |
