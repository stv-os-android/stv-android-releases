# STV OS for the TrimUI Smart Pro S

![The STV OS home screen on the TrimUI Smart Pro S](images/en/home.png)

**Latest version:** 0.0.1-beta (2026-10-10)

## Where does it install?

- **Internal memory:** replaces the factory firmware.
- **microSD card:** the factory firmware stays untouched.

[Which one to choose](releases.md#which-installation-to-choose)

## Where do I download the latest version?

There is one file per installation type in [Available versions](releases.md#available-versions).

## How do I install it?

- [On the internal memory](releases.md#install-on-the-internal-memory): a file on a FAT32 card and a button
  combination.
- [On a microSD card](releases.md#install-on-a-microsd-card): Raspberry Pi Imager on a computer.

## What do I do after installing?

Follow [After installing](releases.md#after-installing): language, time zone, Wi-Fi and where to copy your
games.
