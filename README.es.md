# STV OS

Custom firmware basado en Android 13 para consolas portátiles, optimizado para la emulación de PSP.

> [!WARNING]
> **Beta.** Proyecto independiente y no oficial. Lea la guía de instalación de su consola antes de empezar.

## Dispositivos

| Dispositivo | Estado | Última versión |
|---|---|---|
| [**TrimUI Smart Pro S**](devices/trimui-smart-pro-s/README.es.md) | Beta | [0.0.1-beta](devices/trimui-smart-pro-s/releases.es.md#versiones-disponibles) |
