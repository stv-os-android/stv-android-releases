# STV OS

Un Android 13 a medida para consolas portátiles retro, con un objetivo: lograr la mejor emulación
de PSP que cada consola puede dar.

> **Beta.** STV OS es un proyecto independiente y gratuito. Se prueba en el hardware real, pero
> reemplaza o deja de lado el sistema de fábrica: lea la guía de instalación antes de empezar.

## Dispositivos

| Dispositivo | Estado | Última versión |
|---|---|---|
| [**TrimUI Smart Pro S**](devices/trimui-smart-pro-s/README.es.md) | Beta | [0.0.1-beta](devices/trimui-smart-pro-s/releases.es.md) |

Cada página de dispositivo tiene tres secciones:

- **Presentación**: qué es el proyecto, su objetivo y lo que logra en esa consola.
- **Versiones**: las descargas para la memoria interna y para la microSD, el código fuente del
  kernel de cada versión y cómo instalarlas.
- **Manual**: cómo usar la consola y cada función de STV OS, con capturas.

## Apoyar el proyecto

STV OS es gratuito y no se vende. Si le resulta útil, puede apoyar su desarrollo en
[estebanrios.github.io/stv/support](https://estebanrios.github.io/stv/support/).

## Licencias

STV OS incluye software de terceros, cada uno con su licencia. Cada versión trae un `NOTICE.txt`
con la lista completa y el código fuente que exige la GPL (el kernel y los programas que se
modificaron). STV OS no incluye juegos ni archivos de BIOS.
