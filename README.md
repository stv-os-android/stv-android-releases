# STV OS

A custom Android 13 for retro handhelds, built around one goal: getting the best PSP emulation each
console can give.

> **Beta.** STV OS is an independent project, free of charge. It is tested on real hardware, but it
> replaces or bypasses the factory system: read the installation guide before you start.

## Devices

| Device | Status | Latest version |
|---|---|---|
| [**TrimUI Smart Pro S**](devices/trimui-smart-pro-s/README.md) | Beta | [0.0.1-beta](devices/trimui-smart-pro-s/releases.md) |

Each device page has three sections:

- **Overview**: what the project is, its goal and what it achieves on that console.
- **Releases**: the downloads for internal memory and for microSD, the kernel source code of each
  version, and how to install them.
- **Manual**: how to use the console and every STV OS feature, with screenshots.
