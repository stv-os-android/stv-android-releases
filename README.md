# STV OS

Custom firmware based on Android 13 for handheld consoles, optimized for PSP emulation.

> [!WARNING]
> **Beta.** Independent, unofficial project. Read your console's installation guide before you start.

## Devices

| Device | Status | Latest version |
|---|---|---|
| [**TrimUI Smart Pro S**](devices/trimui-smart-pro-s/README.md) | Beta | [0.0.1-beta](devices/trimui-smart-pro-s/releases.md#available-versions) |
